# Color 色彩

为了避免视觉传达差异，使用一套特定的调色板来规定颜色，为所搭建的产品提供一致的外观视觉感受。

## Main Color 主色

默认的主题色是明亮、友好的蓝色。

- Main Color
  - #409EFF
- Color Scale
  - rgb(51, 126, 204)
  - rgb(121, 187, 255)
  - rgb(160, 207, 255)
  - rgb(198, 226, 255)
  - rgb(217, 236, 255)
  - rgb(236, 245, 255)
